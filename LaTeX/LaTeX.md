
# LaTeX

## 1. Introduction

LaTeX is a document preparation system used to create professional-quality documents. It is widely used in academic writing, research papers, reports, books, and scientific publications.

Unlike ordinary word processors, LaTeX uses commands to control document formatting.

## 2. Features of LaTeX

- Professional document formatting.
- Mathematical equation support.
- Automatic numbering of sections and figures.
- Bibliography and citation management.
- Cross-referencing.
- Table and image insertion.
- Consistent formatting.

## 3. Basic Structure of a LaTeX Document

```latex
\documentclass{article}

\begin{document}

\title{My First LaTeX Document}
\author{Nidhi Panchal}
\date{\today}

\maketitle

\section{Introduction}
This is my first LaTeX document.

\section{Conclusion}
LaTeX is useful for technical writing.

\end{document}
```

## 4. Important Commands

| Command | Purpose |
|---|---|
| \documentclass{} | Defines document type |
| \begin{} | Starts an environment |
| \end{} | Ends an environment |
| \title{} | Sets document title |
| \author{} | Sets author |
| \maketitle | Displays title |
| \section{} | Creates a section |
| \subsection{} | Creates a subsection |
| \textbf{} | Makes text bold |
| \textit{} | Makes text italic |
| \underline{} | Underlines text |
| \includegraphics{} | Inserts an image |
