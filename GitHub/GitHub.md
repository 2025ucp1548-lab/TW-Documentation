
# GitHub

## 1. Introduction

GitHub is an online platform for hosting Git repositories. It provides collaboration, project management, and code-sharing facilities.

## 2. Features

- Repository hosting.
- README documentation.
- Branch management.
- Pull requests.
- Issues.
- Code review.
- GitHub Actions.
- Project management.

## 3. Git vs GitHub

| Git | GitHub |
|---|---|
| Version control system | Online hosting platform |
| Works locally | Provides remote repositories |
| Tracks file changes | Supports collaboration |
| Uses Git commands | Provides a web interface and Git integration |

## 4. Creating a GitHub Repository

1. Sign in to GitHub.
2. Click the New Repository option.
3. Enter a repository name.
4. Add a description.
5. Select Public or Private.
6. Click Create Repository.

## 5. Important GitHub Terms

- Repository: Project storage space.
- Fork: Creates an independent hosted copy.
- Clone: Downloads a repository locally.
- Pull Request: Proposes changes for review and merging.
- Issue: Tracks bugs, questions, and tasks.
- Commit: Records a change.
- Branch: Separate development line.

## 6. GitHub Issues and Projects

Issues help track bugs, features, and tasks.

GitHub Projects helps organize work using boards and tables.

## 7. Pull Request Workflow

1. Create a branch.
2. Make changes.
3. Commit changes.
4. Push the branch.
5. Open a pull request.
6. Review the changes.
7. Merge the pull request.

## 8. Public and Private Repositories

Public repositories can be viewed by everyone.

Private repositories are accessible only to authorized users.

## 9. Conclusion

GitHub makes software development and documentation easier through repository hosting and collaboration tools.
