
# Google Docs

## 1. Introduction

Google Docs is an online word-processing application developed by Google. It allows users to create, edit, format, and share documents.

## 2. Features

- Online document creation.
- Real-time collaboration.
- Automatic saving.
- Comments and suggestions.
- Version history.
- Sharing and access permissions.
- Exporting documents into PDF and DOCX formats.

## 3. Important Formatting Features

| Feature | Purpose |
|---|---|
| Font Style | Changes text appearance |
| Font Size | Changes text size |
| Bold | Highlights important text |
| Italic | Emphasizes text |
| Underline | Underlines text |
| Headings | Organizes document structure |
| Page Numbers | Numbers document pages |
| Table | Organizes information |
| Insert Image | Adds visual content |

## 4. Collaboration

Google Docs allows multiple users to work on the same document.

Users can:
- Edit simultaneously.
- Add comments.
- Suggest modifications.
- Share documents through links.
- Control viewer, commenter, and editor permissions.

## 5. Version History

Version history helps users:
- View previous versions.
- Identify modifications.
- Restore earlier versions.
- Track changes made by collaborators.

## 6. Advantages

- Easy accessibility.
- Cloud-based storage.
- Real-time teamwork.
- Automatic saving.
- Easy sharing.

## 7. Conclusion

Google Docs is a useful tool for collaborative document preparation and technical writing.
